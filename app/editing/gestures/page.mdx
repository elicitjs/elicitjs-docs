# Transforms & Modalities

<Lead>Transforms map user input into channel values through the channel's encoding scale. `move` translates position, `resize` adjusts radial magnitude, `slide` adjusts magnitude along an axis, `rotate` turns angles, and `cycle` advances discrete categories. A mark that accepts pointer drags also accepts keyboard arrow keys through the same edit and constraints.</Lead>

<ApiReference entries={api} />

<Section id="move" title="Position — move">

`move()` inverts the pointer coordinates on each positional channel it governs. On `x` and `y` together it performs a 2D translation; on `y` alone it is a 1D bar drag.

By default, the mark's centre snaps to the pointer. On marks with area (such as `rect` or `sticker`), pass `mode: "relative"` so the mark moves by the drag distance without jumping.

<Example
  code={moveAPoint}
  title="Move a point"
  blurb={"edits: [move({ channels: [\"x\", \"y\"] })] — the pointer inverts onto both positional channels."}
  try={(
    <>
      <b>Drag</b> a dot anywhere.
    </>
  )}
/>

</Section>

<Section id="keyboard" title="Keyboard modality — arrow key nudging">

Every mark that accepts a drag also accepts keyboard input through the same edit and constraints. Press <kbd>Tab</kbd> to focus a mark, then use **arrow keys** to nudge values by 1% of the scale domain (or <kbd>Shift</kbd>+arrow for 10%).

The keyboard shares the same domain clamping and validation as mouse drags. Enable `focusOutline: true` to display the browser's native focus ring.

<Example
  code={keyboardNudge}
  title="Arrow keys move a point"
  blurb="A mark configured with move() accepts arrow keys automatically. Domain clamps hold for both modalities."
  try={(
    <>
      <b>Tab</b> until a dot is focused, then use the <b>arrow keys</b> (or <b>Shift+arrow</b>) to nudge its position.
    </>
  )}
/>

</Section>

<Section id="resize" title="Magnitude — resize (radial)">

`resize()` inverts the drag radius from the mark's centre back into the channel's value (`size: { edit: resize() }`). Stroke widths remain constant while resizing.

<Example
  code={dragOutwardToGrow}
  title="Drag outward to grow"
  blurb="resize() maps the gesture radius back to the size field."
  try={(
    <>
      <b>Drag</b> a dot outward or inward to change its size.
    </>
  )}
/>

</Section>

<Section id="slide" title="Magnitude — slide (linear)">

`slide()` is the linear counterpart to `resize`. It reads how far the pointer moves along one **axis** and maps that onto the value's domain. Set `axis` to `'x'` or `'y'`, and `increase` to `'left'`, `'right'`, `'up'`, or `'down'`.

The default `mode: "relative"` alters the value by the drag delta from where you pressed. `extent` sets the drag distance required to sweep the full domain.

<Example
  code={slideAlongAnAxis}
  title="Slide along an axis"
  blurb={"size: { edit: slide({ axis: \"x\", increase: \"left\" }) } — dragging left increases the value."}
  try={(
    <>
      <b>Drag</b> the dot left to grow it, right to shrink it.
    </>
  )}
/>

</Section>

<Section id="rotate" title="Angle — rotate">

`rotate()` inverts the pointer's angle about a pivot into angular degrees. Set `pivot: "mark"` to rotate around the mark's centre, or `pivot: "plot"` for the chart centre. Set `fold: false` for a full 360° dial, or `fold: true` for a directional cone.

<Example
  code={rotateABox}
  title="Rotate a box"
  blurb="Pointer angle inverts onto theta relative to the mark centre."
  try={(
    <>
      <b>Drag</b> the box to spin it around its centre.
    </>
  )}
/>

</Section>

<Section id="multi" title="Discrete — cycle, and combining gestures">

`cycle()` advances an ordinal channel to the next value in its domain on a `click`. When multiple edits share a mark, `when` arbitrates which edit fires based on modifier keys.

<Example
  code={moveShiftResizeClickCycle}
  title="Move · Shift-resize · click-cycle"
  blurb="when.noShift and when.shift split the drag; cycle() advances the fill category."
  try={(
    <>
      <b>Drag</b> to move · <b><kbd>Shift</kbd>+drag</b> to resize · <b>Click</b> to recolour.
    </>
  )}
/>

</Section>

<Section id="custom" title="Custom transforms">

`custom(fn)` sets `fn` as the edit's `apply` function. It receives an `EditContext` (`ctx.datum`, `ctx.event`, `ctx.pointer`, `ctx.scales`) and returns the updated datum or dataset.

<Example
  code={invertYYourself}
  title="Invert y directly"
  blurb="ctx.pointer contains plot pixels; scales.y.invertValue maps them back to data."
  try={(
    <>
      <b>Drag</b> a dot — y follows the pointer and the data panel reflects the updated field.
    </>
  )}
/>

</Section>
