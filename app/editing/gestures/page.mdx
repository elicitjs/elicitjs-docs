# Transforms & Modalities

<Lead>A transform maps input to a channel's value through that channel's scale. `move` sets position, `resize` and `slide` set magnitude, `rotate` sets an angle, and `cycle` steps through categories. `toggle` adds or removes a row in a slot, `set` writes a value outright, `rank` reorders rows, and `custom` does anything else. A mark that takes a drag also takes the arrow keys, through the same edit and constraints.</Lead>

<ApiReference entries={api} />

<Section id="move" title="Position — move">

`move()` inverts the pointer on each positional channel it governs. On `x` and `y` together it is a 2D drag. On `y` alone it is a 1D bar drag.

By default, the mark's centre snaps to the pointer. On marks with area, such as `rect` or `sticker`, pass `mode: "relative"`: the mark moves by the drag distance and keeps its grab offset.

<Example
  code={moveAPoint}
  title="Move a point"
  blurb={"edits: [move({ channels: [\"x\", \"y\"] })] — the pointer inverts onto both positional channels."}
  try={(
    <>
      <b>Drag</b> a dot anywhere.
    </>
  )}
/>

</Section>

<Section id="keyboard" title="Keyboard modality — arrow key nudging">

Press <kbd>Tab</kbd> to focus a mark, then press the **arrow keys** to nudge its value by 1% of the scale domain. <kbd>Shift</kbd>+arrow nudges by 10%.

A nudge runs through the same edit, clamping and constraints as a drag. Set `focusOutline: true` to show the browser's native focus ring.

<Example
  code={keyboardNudge}
  title="Arrow keys move a point"
  blurb="A mark configured with move() accepts arrow keys automatically. Domain clamps hold for both modalities."
  try={(
    <>
      <b>Tab</b> until a dot is focused, then use the <b>arrow keys</b> (or <b>Shift+arrow</b>) to nudge its position.
    </>
  )}
/>

</Section>

<Section id="resize" title="Magnitude — resize (radial)">

`resize()` inverts the pointer's distance from the mark's centre into the channel's value (`size: { edit: resize() }`). Stroke widths stay constant as the mark grows.

<Example
  code={dragOutwardToGrow}
  title="Drag outward to grow"
  blurb="resize() maps the gesture radius back to the size field."
  try={(
    <>
      <b>Drag</b> a dot outward or inward to change its size.
    </>
  )}
/>

</Section>

<Section id="slide" title="Magnitude — slide (linear)">

`slide()` is the linear counterpart to `resize`. It maps the pointer's travel along one **axis** onto the value's domain. Set `axis` to `'x'` or `'y'`, and `increase` to `'left'`, `'right'`, `'up'` or `'down'`.

The default `mode: "relative"` changes the value by the distance dragged since the press. `extent` sets the drag distance that covers the full domain.

<Example
  code={slideAlongAnAxis}
  title="Slide along an axis"
  blurb={"size: { edit: slide({ axis: \"x\", increase: \"left\" }) } — dragging left increases the value."}
  try={(
    <>
      <b>Drag</b> the dot left to grow it, right to shrink it.
    </>
  )}
/>

</Section>

<Section id="rotate" title="Angle — rotate">

`rotate()` inverts the pointer's angle about a pivot into degrees. Set `pivot: "mark"` to rotate about the mark's centre, or `pivot: "plot"` for the plot's centre. Set `fold: false` for a full 360° dial, or `fold: true` for a directional cone.

<Example
  code={rotateABox}
  title="Rotate a box"
  blurb="Pointer angle inverts onto theta relative to the mark centre."
  try={(
    <>
      <b>Drag</b> the box to spin it around its centre.
    </>
  )}
/>

</Section>

<Section id="multi" title="Discrete — cycle, and combining gestures">

`cycle()` steps an ordinal channel to the next value in its domain on a `click`. When several edits share a mark, `when` picks which one fires by modifier key.

<Example
  code={moveShiftResizeClickCycle}
  title="Move · Shift-resize · click-cycle"
  blurb="when.noShift and when.shift split the drag; cycle() advances the fill category."
  try={(
    <>
      <b>Drag</b> to move · <b><kbd>Shift</kbd>+drag</b> to resize · <b>Click</b> to recolour.
    </>
  )}
/>

</Section>

<Section id="custom" title="Custom transforms">

`custom(fn)` sets `fn` as the edit's `apply`. It fires on a gesture (`drag` by default). `fn` receives an `EditContext` (`ctx.datum`, `ctx.event`, `ctx.pointer`, `ctx.scales`). Return a new datum, or an array of data; the fields you set are written back.

<Example
  code={invertYYourself}
  title="Invert y directly"
  blurb="ctx.pointer contains plot pixels; scales.y.invertValue maps them back to data."
  try={(
    <>
      <b>Drag</b> a dot — y follows the pointer and the data panel reflects the updated field.
    </>
  )}
/>

</Section>
