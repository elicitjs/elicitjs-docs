# Legend pickers & editing

<Lead>A legend can take input as well as label a scale. Click a swatch to set a categorical field, drag a ramp handle to set a continuous value, or double-click to edit the scale's domain. With more than one row, a picker writes to the selected rows.</Lead>

<ApiReference entries={api} />

<Section id="category-picker" title="Categorical swatch pickers">

Pass `edit: edit.legend.category()` to make each swatch a click target. A click sets the channel's field on the target row and recolours the mark.

<Example
  code={categoryPicker}
  title="Click a swatch to set category"
  blurb="A one-row answer whose category is set from the legend."
  try={(
    <>
      <b>Click</b> a swatch to change the status.
    </>
  )}
/>

</Section>

<Section id="selection-target" title="Targeting selected rows">

With several rows, a picker needs a row to write. Its `row` target **defaults to the selection**: click a mark, then a swatch, and that mark updates.

With `edit.select({ multi: true })`, one swatch click updates every selected row at once.

<Example
  code={pickAndEditSelection}
  title="Select bars, then pick a group"
  blurb="Click a bar to select it (or Shift-click for multiple), then click a swatch to reassign its group."
  try={(
    <>
      <b>Click</b> a bar, <b>Shift-click</b> another, then <b>click</b> a legend swatch.
    </>
  )}
/>

</Section>

<Section id="value-picker" title="Continuous ramp sliders">

For a continuous field, `edit: edit.legend.value()` adds a draggable handle to the colour ramp. Dragging it writes that value to the row.

<Example
  code={valuePickerRamp}
  title="Drag the gradient ramp"
  blurb="Dragging the ramp handle updates the numeric temperature value."
  try={(
    <>
      <b>Drag</b> the handle up and down along the gradient ramp.
    </>
  )}
/>

</Section>

<Section id="domain-authoring" title="Authoring categories on the scale">

A swatch picker writes to a row. `edit.scale.categories()` writes to the **scale's domain**.

It adds three controls to the legend: **double-click a swatch** to rename its category, **click the ×** to delete it, and **double-click the ＋** to add a category. A rename updates matching rows, and a delete removes them.

<Example
  code={editTheCategoriesDomain}
  title="Rename, remove, and add categories"
  blurb="Double-click ＋ to append · double-click a label to rename · click × to remove."
  try={(
    <>
      <b>Double-click</b> the ＋ icon to add a category · <b>double-click</b> a label to rename it.
    </>
  )}
/>

</Section>
