# Stages

<Lead>Stages split a question into steps: first do X, then do Y. Give an edit a numeric `stage` and it is active only in that stage; an edit with no `stage` is always active. Stages work with every mark and edit. Move between them with `nextStage()`, `setStage(n)` and `getStage()`, and listen with `on("stage", cb)`.</Lead>

<ApiReference entries={api} />

<Section id="basics" title="Place, then size">

Stage 0 drags the point along `x` (where). Stage 1 resizes it (how confident). Only one edit is live at a time.

A staged [probe](/editing/probe) edit advances the stage when it commits. Set `advance: false` on it to advance by hand instead.
