# Area

<Lead>`area` fills the region under a series. It groups and orders rows as [`line`](/marks/line) does, and takes the same handles, drags and sweeps. `areaY` fills to the `y` baseline, `areaX` to the `x` baseline. Give the value axis an endpoint pair (`y1` + `y2`) and it fills between them instead, as an **uncertainty band** you edit by both edges.</Lead>

<ApiReference entries={api} />

<Section id="basics" title="Filled series">

Drag a handle to reshape the curve. Each handle takes the area's colour. By default, handles draw only when the area carries an edit; `handles: true` draws them without one.

<Section id="hit" title="Invisible handles">

`handles: 'hit'` keeps the handles grabbable but invisible, as on `line` and `arc`. `handles: false` removes them entirely; a sweep or nearest pick then has nothing to target and logs a warning.

<Section id="gradient" title="Gradient fill">

`gradient: { stops, direction }` fills the area with a linear gradient instead of a flat `fill`. Each stop is `[offset, colour]`, with `offset` from 0 to 1 across the area's own box. `direction: 'vertical'` (the default) runs from bottom (0) to top (1); `'horizontal'` runs left to right. `bar` and `rect` take the same option.

<Example
  code={aGradientFill}
  title="A gradient fill"
  blurb={"gradient: { stops: [[0, pale], [1, blue]] } fades the area toward its baseline."}
  try={(
    <>
      <b>Drag</b> a handle — the gradient stretches over the new shape.

  )}
/>

</Section>

<Section id="band" title="Uncertainty band">

Give the value axis an endpoint pair and the area fills between them, as in a confidence interval or a fan chart. Both edges get handles, so you set the interval by dragging its ends. Add the [ordering](/constraints#ordering) constraint to keep the band the right way up: drag the low edge above the high one and the high edge moves with it, since the edge you grabbed is the one you meant.

<Example
  code={anEditableConfidenceBand}
  title="An editable confidence band"
  blurb="areaY with a y1/y2 pair; ordering keeps lo ≤ hi."
  try={(
    <>
      <b>Drag</b> either edge — push the low edge past the high one and the band moves rather than turning inside-out.
    </>
  )}
/>

A row whose value is `null`, `undefined` or `NaN` breaks the area or band there, as on a [line](/marks/line#gaps), and has no handle. To repaint one edge in a single drag, put `edit.line.sweep()` on `y1` and `y2`; see [Sweeping a band](/editing/sweep#band).

</Section>
