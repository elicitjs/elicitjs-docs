# Area

<Lead>A filled path under a series — the distributional sibling of `line`. Same grouping / ordering knobs; optional handles so sweep and drag reuse the line edit machinery. `areaY` fills to the y baseline; `areaX` to the x baseline. Declare an endpoint **pair** instead (`y1` + `y2`) and it fills **between** them rather than down to the baseline — an **uncertainty band**, editable by both edges.</Lead>

<ApiReference entries={api} />

<Section id="basics" title="Filled series">

Drag handles to reshape the belief curve. Each handle is filled with the area's colour. Handles draw only when the area carries an edit.

<Section id="hit" title="Invisible handles">

`handles: 'hit'` keeps the grab targets without drawing the circles — the shared contract with `line` and `arc`. `false` is neither drawn nor grabbable, so a sweep or nearest pick has nothing to target and the chart warns.

<Example
  code={hitHandles}
  title="handles: 'hit'"
  blurb="Same area as Basics; the grips are invisible but still dragable."
  try={(
    <>
      <b>Drag</b> along the upper edge where a handle would sit.
    </>
  )}
/>

</Section>

<Section id="gradient" title="Gradient fill">

`gradient: { stops, direction }` paints the area with a linear gradient instead of a flat `fill`. Each stop is `[offset, colour]`, with `offset` from 0 to 1 across the area's own box. `direction: 'vertical'` (the default) runs from bottom (0) to top (1); `'horizontal'` runs left to right. `bar` and `rect` take the same option.

<Example
  code={aGradientFill}
  title="A gradient fill"
  blurb={"gradient: { stops: [[0, pale], [1, blue]] } fades the area toward its baseline."}
  try={(
    <>
      <b>Drag</b> a handle — the gradient stretches over the new shape.
    </>
  )}
/>

</Section>

<Section id="band" title="Uncertainty band">

Give the value axis an endpoint **pair** and the area fills between them — the shape of a confidence interval or a fan chart. Both edges get handles, so the interval is elicited by dragging its ends. Pair it with [ordering](/constraints#ordering) so the band cannot be turned inside-out: drag the low edge above the high one and the high edge is carried along, because the edge you grabbed is the one you meant.

<Example
  code={anEditableConfidenceBand}
  title="An editable confidence band"
  blurb="areaY with a y1/y2 pair; ordering keeps lo ≤ hi."
  try={(
    <>
      <b>Drag</b> either edge — push the low edge past the high one and the band moves rather than turning inside-out.
    </>
  )}
/>

A row whose value is `null`, `undefined` or `NaN` breaks the area or band there, as it breaks a [line](/marks/line#gaps), and gets no handle. To repaint one edge in a single drag, put `edit.line.sweep()` on `y1` and `y2`; see [Sweeping a band](/editing/sweep#band).

</Section>
