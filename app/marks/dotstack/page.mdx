# Stacked dots

<Lead>`dotStack` draws a **dot histogram**: each row is one token, and tokens in the same slot stack into a countable column. Click an empty slot to add a token (`create`), and click a token to remove it (`remove`). The answer is the number of tokens in each slot: `data.filter(d => d.bin === b).length`.</Lead>

<ApiReference entries={api} />

<Section id="basics" title="Dropping tokens">

Click to drop a token into the nearest slot. Click a token to take it back. `count()` caps the budget.

<Section id="orientation" title="Orientation">

Put the slots on `y` and tokens stack rightward instead of up. `dotStackY` and `dotStackX` force a direction. Bare `dotStack` takes it from the channels: the slot channel's axis holds the categories, and tokens stack along the other. `orientation: "horizontal" | "vertical"` sets it explicitly, as on `bar` and `waffle`.
