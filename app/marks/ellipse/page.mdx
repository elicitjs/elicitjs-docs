# Ellipse

<Lead>`ellipse` draws a dot with two radii, `rx` and `ry`. Each is its own channel, with its own field and its own edit, so one mark elicits two numbers. `size` sets any radius you leave unset.</Lead>

<ApiReference entries={api} />

<Section id="uncertainty" title="Two uncertainties, one blob">

Use an ellipse for an estimate with per-axis uncertainty. The centre is the estimate, and each radius is the uncertainty along its axis.

Both radius edits are on the same mark, so one diagonal drag reshapes the blob. `slide({ axis: 'x' })` and `slide({ axis: 'y' })` read different components of the drag, so they work together.

<Section id="movable" title="Moving it as well">

Two edits that read the same component of a drag conflict on one mark: a `move()` on the centre and a radius `slide` would both fire. Gate one with `when` (for example `when.shift`, as on [Shape](/marks/shape#path)), or give each its own mark in a [composite](/marks/composite): an `ellipse` that resizes, and a `point` at its centre that moves. Direct pick sends each drag to the mark you touched.

<Section id="glyphs" title="Inside a glyph">

A [face](/marks/face) draws its eyes with `ellipse`: an `rx` that opens and an `ry` that squints, both set as fractions of the glyph's frame so they scale with the head. See [composite](/marks/composite#box) for how a mark places itself in a glyph's local coordinates.

</Section>
