# Tick

<Lead>`tick` draws a line at a value on one axis, spanning the other axis. Over a category band it marks a value per category; with no band it spans the full extent, as a rug or strip plot. `tickY` and `tickX` force the value axis; `tick` infers it. `inset` shrinks each end, and `length` sets a fixed, centred length.</Lead>

<ApiReference entries={api} />

<Section id="value-marker" title="A value marker across bands">

`tickY` marks a `y` value across each category's band. It takes the same channels and edits as a `bar`, and drags the same way.
