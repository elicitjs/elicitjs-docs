# Needle

<Lead>`needle` draws a tapered pointer and hub for a gauge or dial. Its value is on the `theta` channel, and the `theta` scale's `range` sets the sweep in degrees: the default `[180, 0]` runs left to right through the top. Set `orient`, `arc` or `start`/`end` on the companion `axisRadial`, and keep its range matched to the needle's. `x`/`y` place the pivot, for many small needles in one chart.</Lead>

<Section id="ableton" title="Ableton-style knob">

A software knob is a [composite](/marks/composite) of a ring (a dark track and a value fill) and a thin `needle` on the same `theta` scale. `arc` and `donut` divide a total among rows, but a knob's fill is one value swept from the arc's start, so the ring is a small custom mark built on `authoring.arcPath`. The needle carries `rotate({ pivot: "mark", fold: false, pick: "direct" })`. The ring has no edit and re-derives as you drag.

The span is a 270° arc with a gap at the bottom: `start: 225` (about 7 o'clock) to `end: -45` (about 5 o'clock). Set the needle's `scale.range` to the same span.
