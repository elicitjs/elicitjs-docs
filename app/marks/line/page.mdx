# Line

<Lead>`line` draws a connected path through ordered points, with a draggable handle on each point once the line carries an edit. One mark covers a you-draw-it curve, a multi-series chart and a connected scatter: `series` groups rows into lines, `order` or `connect` orders them, and `edit.line.anchor` / `newSeries` / `draw` create them. `lineY`/`lineX` fix the value axis; `path` defaults to `connect: "sequence"`.</Lead>

`lineY` draws a value on `y` over a domain on `x` (the usual time series). `curve` sets the interpolation between handles.

<Section id="gaps" title="Missing values">

A row whose value is `null`, `undefined` or `NaN` breaks the line there. The segments on either side draw on their own, and the missing row gets no handle.

</Section>

<Section id="dashes" title="Dashed lines">

`strokeDash` sets the dash pattern. A constant is an SVG dash array (`strokeDash: '4 2'`). A field maps each category onto a dash pattern (solid, dashed, dotted, dash-dot, long dash), as `stroke` maps one onto a colour. Add `legend: true` to the channel for a key of dashed segments.

<Example
  code={dashedByField}
  title="Observed and forecast"
  blurb={"strokeDash: { field: \"kind\" } draws the forecast dashed; series: { field: \"kind\" } splits the two lines."}
  try={(
    <>
      <b>Drag</b> a forecast point.
    </>
  )}
/>

Rows group into lines by `series`. Without it, they group by the field on `fill`, `stroke` or `strokeDash`, so a `strokeDash` field alone also splits the lines.

</Section>

<Section id="you-draw-it" title="You-draw-it (sweep)">

Put `edit: move({ pick: "sweep" })` on the value channel for a you-draw-it line. Press and sweep horizontally to paint each point's `y` as the pointer crosses its column. The `x` positions stay fixed.

<Example
  code={sweepToDrawTheCurve}
  title="Sweep to draw the curve"
  blurb="The value channel carries a sweep; guide: true shows the paint guide."
  try={(
    <>
      <b>Sweep</b> left-to-right across the chart — or drag a single handle.
    </>
  )}
/>

</Section>

<Section id="handles" title="Hiding the handles">

By default, handles draw only where an edit can move the row. A line with no edit has none, and neither does a `lock`ed or `context` row, or a line whose edits wait for a later `stage`. `handles: true` draws them on every row, with or without an edit. `handles: 'hit'` keeps them grabbable but invisible, so a sweep or nearest pick still finds the line. `handles: false` removes them entirely; a proximity edit then has nothing to target and logs a warning. `handleSize` sizes them when shown.

<Example
  code={aCleanLineStillSweepable}
  title="A clean line, still sweepable"
  blurb="handles: 'hit' hides the dots; the sweep edit still works."
  try={(
    <>
      <b>Sweep</b> across — no handles, but the line still responds.
    </>
  )}
/>

</Section>

<Section id="series" title="Multiple lines (series)">

The `series` channel groups points into separate lines, so one mark holds many series. Without `series`, the field on `fill`, `stroke` or `strokeDash` groups them. A `stroke` field both groups and colours the lines from the ordinal palette. A sweep locks onto the nearest line when the drag starts and paints only that one.

<Example
  code={twoSeriesSweptIndependently}
  title="Two series, swept independently"
  blurb={"stroke: { field: \"g\" } both groups and colours the lines."}
  try={(
    <>
      <b>Sweep</b> over one line to reshape it; the other stays put.
    </>
  )}
/>

</Section>

<Section id="connected-scatter" title="Connected scatter (connect: sequence)">

With `connect: "sequence"`, points connect in row order instead of domain order, giving a connected scatter or a free 2D path. Both axes carry a drag here, so each point moves in 2D and the links follow. `edit.line.anchor()` appends a point wherever you click, extending the one path in click order.

<Example
  code={a2dPathYouCanReshape}
  title="A 2D path you can reshape"
  blurb={"path defaults to connect: \"sequence\"; a 2D drag moves points, anchor extends the one path in click order."}
  try={(
    <>
      <b>Drag</b> a point anywhere, or <b>click</b> empty space to add the next anchor.
    </>
  )}
/>

</Section>

<Section id="samples" title="Draw from scratch (samples)">

`newSeries` seeds a whole line at once, flat at the clicked value. It places one anchor per sampled domain position: the scale's ticks by default, or a count, an explicit list, or a time interval. Double-click empty space to drop a fresh line, then sweep it.

<Example
  code={doubleClickToSeedThenSweep}
  title="Double-click to seed, then sweep"
  blurb={"edit.line.newSeries({ samples: 6 }) drops six evenly-spaced anchors at the click’s value."}
  try={(
    <>
      <b>Double-click</b> to drop a line, then <b>sweep</b> to shape it.
    </>
  )}
/>

</Section>

<Section id="draw" title="Draw it in one drag (draw)">

`draw` creates lines by dragging. On a domain-ordered line, a drag in empty space draws from scratch: as the pointer crosses each sample column, it lays that point down at the pointer value, so one stroke draws the curve. A later drag within `threshold` of the drawn line reshapes it with a sweep. A drag farther away draws another line. Pass `into: "new"` to always draw a fresh line.

<Example
  code={drawThenReshape}
  title="Draw, then reshape"
  blurb={"edit.line.draw({ samples: 8 }) on an empty line. First drag draws all eight points; a drag over the line reshapes it, a drag in empty space starts a new one."}
  try={(
    <>
      <b>Press and drag</b> to draw · <b>drag over the line</b> to reshape · <b>drag elsewhere</b> for a new line.
    </>
  )}
/>

</Section>
