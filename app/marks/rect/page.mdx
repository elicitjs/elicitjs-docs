# Rect

<Lead>`rect` draws a rectangle whose extent on each axis resolves separately: a **span** (`x1`/`x2`, `y1`/`y2`), a fixed pixel **size** (`width`/`height`) centred on an anchor, a categorical **band**, or a baseline→value length. Use it for heatmap cells, 2-D regions, binned histograms and annotation boxes, and edit it with `brushRect()`. `rectX` / `rectY` force one axis to a baseline→value length. When one axis is a band and the other a value, use [`bar`](/marks/bar).</Lead>

<Section id="heatmap" title="Heatmap (both axes categorical)">

Put a category on both axes and each row draws one cell at that (`x`, `y`) intersection, giving a heatmap. A quantitative `fill` resolves to a sequential colour ramp, a categorical `fill` to a palette. Band scales pad by default; set `scale: { padding: 0 }` on each axis so the cells touch. A drag can't invert a colour, so edit a cell's value through the legend: `select()` on the cells makes the one you click the target row, and `legendColor({ edit: edit.legend.value() })` drags that row's value along the ramp.

<Section id="fixed-size" title="Fixed-size boxes (width/height)">

Give an axis a pixel extent with `width` (x) or `height` (y) and the rect becomes a fixed-size box centred on its `x`/`y` anchor. An explicit size overrides the band interval and the baseline→value length. The anchor is a positional channel, so a `move()` on `x` and `y` moves the whole box.

<Example
  code={fixedSizeBoxes}
  title="Boxes at data points"
  blurb="x/y anchor each box; width/height set a constant 28×28 px size."
  try={(
    <>
      <b>Drag</b> a box to move it (its size stays fixed).
    </>
  )}
/>

</Section>

<Section id="histogram" title="Binned histogram (rectY)">

<Section id="editing" title="Composable 2-D editing (brushRect)">

`brushRect()` edits all four extents. Grab an edge to resize one side, a corner to resize two extents, or the body to move the whole rect. `resize` (`'both' | 'x' | 'y' | 'none'`) sets which axes resize. `move` (boolean) turns the body drag on or off. Together they give resize-one-axis, move-only and resize-only variants.

<Section id="creating" title="Creating rects">

`create()` works on a rect as on any data mark (see [Create · Remove · Anchors](/editing/existence)). A click gives one point and a rect needs a size, so the creator must seed the extent. A `rectY`-style rect (band or baseline→value length) takes its size from the axis and creates like a `bar`. A 2-D span rect (`x1`/`x2`, `y1`/`y2`) needs the opposite corner from `create({ defaults: { x2, y2 } })`; `brushRect()` then shapes it. Without an extent, the new row mints at zero size, invisible, and logs a warning. On a map, `edit.geo.createRect()` mints a box sized from default spans around the click.

</Section>
