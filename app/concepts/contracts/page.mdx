# Mark & element contracts

<Lead>
  What every factory is for: its kind, whether create and remove apply, and
  what you grab. Axes, grids and legends are on <code className="inline">{"elements.*"}</code>.
</Lead>

<Section id="kinds" title="Kinds of factory">

<KindsTable />

Data, parametric and map-chrome factories are all marks: they view rows. An element views a scale. Guides, the third kind on [Core concepts](/concepts#feature-kinds), view state and are covered on [Guides](/guides).

Marks are **inert** until an edit names the column it writes. Edits write **fields**, so an edit goes on a <code className="inline">{"{ field }"}</code> channel. A constant <code className="inline">{"{ value }"}</code> channel carries none.

</Section>

<Section id="data" title="Data marks">

<DataMarksTable />

On every mark that draws a grip, <code className="inline">handles</code> takes <code className="inline">true</code> (drawn and grabbable), <code className="inline">false</code> (hidden and inert), or <code className="inline">&apos;hit&apos;</code> (invisible but grabbable).

</Section>

<Section id="parametric" title="Parametric glyphs">

<ParametricTable />

Set a stage on the edit, as in <code className="inline">{"edit.trend.slope({ stage: 1 })"}</code>. The mark takes no stage option.

</Section>

<Section id="elements" title="Chart elements">

Chart elements are exported as <code className="inline">{"elements.*"}</code>. Pass them in <code className="inline">elements: [...]</code> on the spec, or inside <code className="inline">marks</code>; both lists draw together, elements first.

<ElementsTable />

<Section id="feedback" title="Guides and effects">

An edit's <code className="inline">guide:</code> option draws its rules: <code className="inline">bounds</code>, <code className="inline">catchment</code> and <code className="inline">track</code>. An **effect** shows interaction state: <code className="inline">hovered</code>, <code className="inline">selected</code> or <code className="inline">grabbed</code>. Edits that select a target (<code className="inline">{'pick: "nearest"'}</code>, <code className="inline">{'pick: "sweep"'}</code>, <code className="inline">brushSpan</code>, <code className="inline">brushRect</code>, <code className="inline">edit.geo.brush</code>) turn catchment on when you omit <code className="inline">guide</code>. Set <code className="inline">guide: false</code> to turn it off. See [Guides](/guides) and [Effects](/effects).

</Section>
