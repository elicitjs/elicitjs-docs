<Section id="kinds" title="Four kinds">

<KindsTable />

Marks are **inert** until an edit names the column it writes. Edits write **fields** — a constant <code className="inline">{"{ value }"}</code> channel cannot carry an edit.

</Section>

<Section id="data" title="Data marks">

<DataMarksTable />

<code className="inline">handles</code> is <code className="inline">true</code> (drawn + grabbable), <code className="inline">false</code> (neither), or <code className="inline">&apos;hit&apos;</code> (invisible but grabbable) on every mark that draws a grip.

</Section>

<Section id="feedback" title="Guides and effects">

A **guide** shows a rule (<code className="inline">edit.guide</code> — <code className="inline">bounds</code> / <code className="inline">catchment</code> / <code className="inline">track</code>). An **effect** shows state (<code className="inline">hovered</code> / <code className="inline">selected</code> / <code className="inline">grabbed</code>). Proximity picks (<code className="inline">nearest</code>, <code className="inline">sweep</code>, brush*) auto-enable catchment when you omit <code className="inline">guide</code>; set <code className="inline">guide: false</code> to silence. See [Guides](/guides) and [Effects](/effects).

</Section>
