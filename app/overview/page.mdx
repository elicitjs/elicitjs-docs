# Overview

<Lead>ElicitJS builds elicitation interfaces from charts. People drag a bar or place a point, and you get structured data back. An interface is built through a declarative spec, `Elicit(spec)`: one **schema**, one **dataset**, and a list of **marks**. Every example on these pages runs the code beside it. [Core concepts](/concepts) explains the model.</Lead>

<Section id="encode-edit" title="Encoding, and its inverse">

Attach an edit to a channel and a gesture writes that channel back through the **same** scale. The bar below matches the one above, except `y` now carries `edit: move()`. Encoding maps data to height; the edit maps a drag back to data.
