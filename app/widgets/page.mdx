# Widgets

<Lead>**Widgets** are ready-made elicitation interfaces for survey questions. Each one returns an `ElicitSpec` built from ordinary marks, edits and constraints, with option rings, cell grids and tracks drawn as [guides](/guides). Render one with `Elicit(widgets.likert({…}))`. The Likert scale below appears both as a widget and as the plain-API spec it expands to.</Lead>

<ApiReference entries={api} />

<Section id="likert" title="Likert scale — widget & plain API">

A point on a band of options, a `create({ pick: "probe" })` edit, and `count({ max: 1, strategy: "replace" })`. Hover to preview the answer, and click to set it. The plain-API version uses the same mark, edit and constraint, and draws the same look with inline `guides.custom` helpers.

<Section id="choice" title="Multiple choice">

`toggle()` combines create and remove in one gesture. Click an empty option to pick it, and click your pick to take it back. `count()` caps the number of picks.

<Section id="slider" title="Slider">

A single knob that follows the pointer and settles when you click or release a drag: `move({ pick: "probe" })`. `snap()` lands it on steps.

<Section id="matrix" title="Question matrix">

Questions on a band y, options on a band x. `toggle()` on (x, y) picks a cell, and `unique({ field: "question", strategy: "replace" })` keeps one answer per row.

<Example
  code={asAWidget3}

  try={"answer each row; click a row again elsewhere to change it."}

</Section>

<Section id="linecone" title="Line + Cone">

A two-step correlation question. Aim the line and click, then open the cone and click. `getData()` returns `[{ r, spread }]`, and `on("stage")` reports which question you are on (2 = both answered).

It is a preset over [`trendBand`](/marks/trend#band) and [`trend`](/marks/trend) on one dataset. A pinned `intercept: { datum: 0 }` channel and two `clamp` constraints state the correlation. The trend page has [the same spec written out](/marks/trend#correlation). The inner plot is square, so the line’s screen angle reads as `r`.

<Example
  code={asAWidget4}
  title="Line + Cone"
  blurb="Crosshair frame and high/low variable labels are guides."
  try={"move, click, move, click."}
/>

</Section>

<Section id="styles" title="Customizing styles">

Every widget accepts a `theme`, which restyles the answer ink, chrome and affordances together. See [Theming](/theming). For a one-off change, edit the [plain-API version](#likert): repaint the answer mark or swap a guide. The edits and constraints stay the same.

<Example
  code={themedWidget}
  title="Restyle with a theme"

  try={"drag the knob — only the look changed."}
/>

</Section>

`interval` is three `move()` handles over one row, coupled by [constraints](/constraints#follow). `follow` carries the caps with the mean, `ordering` keeps lo ≤ mean ≤ hi, and `clamp` holds all three inside `domain`. `symmetric: true` adds `symmetric`, so dragging one cap mirrors the other about the mean.
